##  Sobre o Projeto

O **Business Pro** é um modelo de demonstração (template) focado em conversão. O design utiliza princípios de UX (User Experience) para guiar o usuário desde a proposta de valor no *Hero* até a ação final no formulário de orçamento.

> **Nota:** Este projeto foi construído para ser totalmente adaptável, servindo como base sólida para diversos nichos de serviços.

---

##  Funcionalidades

* **Design Responsivo:** Adaptado para dispositivos móveis, tablets e desktops.
* **Menu Mobile:** Navegação intuitiva com menu lateral "hamburger".
* **Integração WhatsApp:** Botão flutuante e formulário com gatilho direto para atendimento via API do WhatsApp.
* **Conformidade LGPD:** Inclui barra de consentimento de cookies e avisos de privacidade no formulário.
* **Animações Suaves:** Transições e efeitos de hover para uma experiência de usuário premium.

---

##  Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de dados.
* **CSS3:** Estilização avançada com Flexbox e Grid Layout.
* **JavaScript (ES6):** Lógica para menu mobile, consentimento de cookies e manipulação do formulário.
* **Google Fonts:** Tipografia "Plus Jakarta Sans" para leitura moderna.
* **Font Awesome:** Biblioteca de ícones vetoriais.

##  Como Executar

1. Clone este repositório:
```bash
git clone https://github.com/seu-usuario/business-pro.git

```


2. Navegue até a pasta do projeto:
```bash
cd business-pro

```


3. Abra o arquivo `index.html` em seu navegador de preferência ou utilize a extensão **Live Server** do VS Code.

##  Destaques Técnicos

* **SEO:** Uso de tags semânticas (`<header>`, `<section>`, `<footer>`) para melhor indexação em motores de busca.
* **Performance:** Carregamento otimizado de fontes e ícones via CDN.
* **Segurança:** Uso de `rel="noopener"` em todos os links externos para proteção de segurança e performance.
